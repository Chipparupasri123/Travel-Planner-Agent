# 🌍 Travel Planner Agent
## Project Overview
Travel Planner Agent is an AI-powered travel assistant developed using IBM watsonx Orchestrate and IBM Granite Models. The system helps users plan personalized trips by generating travel itineraries, destination recommendations, accommodation suggestions, transportation guidance, and travel tips.

## Problem Statement
Travel planning often requires users to search multiple websites for destinations, hotels, transportation, budgets, and attractions. This process can be time-consuming and overwhelming.
The Travel Planner Agent simplifies this process by providing intelligent and personalized travel recommendations through a conversational interface.

## Features
* ✈️ Personalized Trip Planning
* 🌍 Destination Recommendations
* 📅 Day-Wise Itinerary Generation
* 🏨 Hotel Suggestions
* 🚆 Transportation Recommendations
* 💰 Budget-Based Planning
* 💡 Travel Tips and Guidance

## Technology Used
* IBM watsonx Orchestrate
* IBM Granite Foundation Model
* IBM Cloud Lite
* Prompt Engineering
